# Content and rights
- Sentences, Lantern prompts and game copy: written for this project; CC0. A starter bank of seven languages; the guess picker accepts about sixty language names. Expansion should be reviewed by fluent speakers.
- Words, country names, capitals, artist names, dates and coordinates are factual data. No lyrics, recordings or album art copied.
- Country outlines/label points: Natural Earth 1:110m Admin 0, public domain, https://www.naturalearthdata.com/about/terms-of-use/ ; downloaded 2026-11-04 from https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson and quantized to 0.01 degrees. Outlines are illustrative, not a position on disputed borders.
- Artist track and genre hints come from the existing music.json. Decade = first solo/studio album for the artist entry, not birth decade.
- Pingle: only yesterday's aggregated city rows with at least two distinct visitors, rounded to one decimal, queried on server. Never individual visits.
- All files here are server input. Vercel blocks /games/data/*; the server includes these files explicitly. Public option lists contain no daily selection seed.
