# Impact video metrics

A measured zero is displayed as 0; a supported but unavailable count as —; a metric the platform does not expose as n/a. A partial score sums only the observed terms. Hover/focus a number to see its source. Provider data (Oriane) is identified separately from official, scraped and manual data. View counts and impressions are labelled separately; they are not unique people.

## Connect the owner sources

Use the **Production** environment of the existing Vercel project (or run `vercel env add NAME production` in the linked checkout). Never put tokens in client-side config or messages. Redeploy after changing Vercel env. The public fallback worker needs no social login.

1. **Instagram (biggest gap: shares and saves).** Switch each IG account to Creator or Business, link it to its Facebook Page, then create a Meta developer app with **Instagram API with Facebook Login**. Add the account managing the Page as an app role for development. Use that app in Graph API Explorer to authorize `instagram_basic`, `instagram_manage_insights`, `pages_show_list` (Page discovery) and `pages_read_engagement`. Query `/me/accounts?fields=id,name,instagram_business_account{id,username}` to identify the correct IG user ID. Exchange the short-lived user token server-side for a long-lived token; renew before expiry. Use app review/advanced access if serving users outside app roles. Set **IG_USER_ID_GABE_MAXXING** + **IG_ACCESS_TOKEN_GABE_MAXXING**, and **IG_USER_ID_GABINHO_BJJ** + **IG_ACCESS_TOKEN_GABINHO_BJJ**. Click Sync now for Instagram. The adapter checks the token's username, matches media IDs by exact permalink, and reads views, shares and saved from media Insights. It never guesses private metrics. [Meta guide](https://www.postman.com/meta/instagram/documentation/6yqw8pt/instagram-api).
2. **TikTok.** Authorize each owner via Login Kit/Display API with `video.list` and set **TIKTOK_ACCESS_TOKEN_GABRIELLVL**, **TIKTOK_ACCESS_TOKEN_GABINHO_BJJ**, **TIKTOK_ACCESS_TOKEN_GABE_MAXXING**. Supply renewed owner tokens before expiry. Display exposes views, likes, comments and shares; collectCount/saves may be available on the public post. Verification challenges and 429s are recorded, never bypassed. [Official fields](https://developers.tiktok.com/doc/tiktok-api-v2-video-object/).
3. **X (optional; public extraction works today).** **X_BEARER_TOKEN** enables the official public_metrics lookup. It includes impressions, likes, replies, reposts, quotes and bookmarks; absence is not zero. X pricing checked Nov 10 2026: standard post reads $0.005/resource; eligible owned reads $0.001/resource on the owner timeline endpoint, not the application's bulk post lookup. No subscription or credits purchased by Corvus. [Current pricing](https://docs.x.com/x-api/getting-started/pricing).
4. **YouTube.** In a Google Cloud project you control, enable [YouTube Data API v3](https://console.cloud.google.com/apis/library/youtube.googleapis.com), [create a key](https://console.cloud.google.com/apis/credentials) and restrict it to this API. Set **YOUTUBE_DATA_API_KEY**. No social login required to read public viewCount. For private shares, authorize the owner for `yt-analytics.readonly` and `youtube.readonly` and supply an unexpired **YOUTUBE_ANALYTICS_ACCESS_TOKEN**. These are different credentials. Production: a YouTube-only API key was created in the personal **Corvus Impact Metrics** Google Cloud project, verified against a real video, and stored as a sensitive Vercel Production variable. No billing account was added. [Data API](https://developers.google.com/youtube/v3/docs/videos#statistics), [owner Analytics](https://developers.google.com/youtube/analytics/reference).
5. **Twitch.** [Register an application](https://dev.twitch.tv/console/apps); copy its Client ID and generate a Client Secret. Set **TWITCH_CLIENT_ID**, **TWITCH_CLIENT_SECRET** in Vercel Production. The server obtains its own app access token. Twitch clips/VODs expose views; the other four comparable counters are n/a.
6. **Oriane (optional).** **ORIANE_API_KEY** is a provider fallback for IG/TikTok. Leave it unset if you prefer the owner/public sources. LinkedIn requires no key: paste original video URLs and analytics in /admin → Compound impact → LinkedIn. Enter impressions OR video views, reactions, comments, reposts and saves. Leave absent values blank. Source: self-reported (manual).

## Measured, not inferred

The hosted job runs at minute 12 each hour. Newly published/imported posts are due hourly; older posts daily. The Mac fallback polls a Redis queue while awake. Successful reads preserve per-field provenance. A public fallback never replaces an available official count. Samples are stored by post and UTC observation hour, with raw edit history. First-day velocity uses the latest genuine observation from the first 24 hours after **publication**, divided by actual elapsed hours; importing an old post does not manufacture its first day. Backfill uses the original observation timestamps and exact post identity. An empty hour has no plotted measurement.

## Extractor evaluation · 10 November 2026

Checked GitHub commits and current issues for [yt-dlp](https://github.com/yt-dlp/yt-dlp), [TikTokApi](https://github.com/davidteather/TikTok-Api), [Instaloader](https://github.com/instaloader/instaloader) and [twscrape](https://github.com/vladkens/twscrape). Latest commits seen: Nov 4, Aug 24, Nov 1 and Nov 6, respectively. TikTokApi has [empty response reports](https://github.com/davidteather/TikTok-Api/issues/1311); Instaloader has [Reels/login issues](https://github.com/instaloader/instaloader/issues/2795); twscrape has [timeline limitations](https://github.com/vladkens/twscrape/issues/377). Those three were not installed or assumed operational.

Pinned yt-dlp 2026.10.26; checksum verified against release. Ran metadata-only probes without cookies: Gabe's X post returned impressions, likes, replies and reposts; the same post response exposed quote and bookmark counts. Gabe's IG reel returned likes/comments but no plays in yt-dlp; the public Reels grid returned plays. LinkedIn returned a public reaction count, not impressions (automatic LinkedIn ingestion intentionally disabled). Real control videos on TikTok, YouTube and Twitch returned play/view counts. Control posts never enter the registry. Public extraction is a fallback, not a stable platform contract.
