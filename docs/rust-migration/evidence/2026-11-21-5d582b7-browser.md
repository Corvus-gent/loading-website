## Conditions

Same built HTML/assets, same local API fixtures, paired alternating legacy JS vs current Rust/WASM bridges. One unrecorded warmup per route/profile. Cold-context means fresh browser HTTP/storage context, not a cold browser process or serverless start; warm reload retains that context. Static assets use HTTP cache/ETags and Brotli quality 4. CSP blocks external requests; no third-party analytics/embeds, real providers or mutations. Returning-visitor gate cookie and explicit analytics refusal. Ready means search/directory usable or CV interactions mounted. Action is a synthetic DOM event to two animation frames, not field INP. LCP/CLS are bounded lab observations, not real-user percentiles.

Browser 156.0.8078.4; darwin/x64; Apple M1 Pro. 40 ms fixed fixture API delay. Bundle 2108863 raw bytes, SHA-256 3268504938d7b31a94992861518d4d4f15309ba12858c921429255e5fd677873.

- Only listed page flows are measured; not a whole-site pass.
- API/Redis, serverless cold starts, real-network CDN regions and field INP remain separate release gates.
- Timing is local and hardware-specific. Fewer than 20 repetitions are exploratory; no release speedup claim.
- Known public pages select the core WASM profile through an import map; feature pages still retain the full bundle until their profiles pass parity. Production publishing remains a separate gate.
