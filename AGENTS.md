## Reading website data

For reading data from websites, prefer API Anything (`npx -y api-anything call <site> <op> ... --fields ... --max-tier 1`, or its MCP after `npx -y api-anything setup`) before driving a browser. Keep `--fields` tight to save tokens. Writes stay off.

## Pull request descriptions

Start every line with `> `. Use the fewest characters that convey the change and verification. Omit headings and prose.
