# hackersbay

Build a pixel parrot pirate and find three Demo Day crewmates in a terminal. Node.js 20 or later. No runtime dependencies.

From the project checkout:

```sh
npx --package ./apps/cli hackersbay
npx --package ./apps/cli hackersbay --class deckhand --name "Copper Byte" --quick
```

Use the arrow keys to choose a class and gear. Select the name row to type a nickname. Press **Enter** for matches and a shareable boarding link. Use `--json` for script output. The CLI ships a labeled fictional roster for offline use.

The package is ready to publish. These local commands work before it is available on npm. [Open The Hackers Bay](https://corvus.gent/hackersbay)
