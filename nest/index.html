What actually happens.

Muse Ember generates the page. Corvus supplies the interface and safety checks. The preview allows HTML and CSS, with scripts, forms and external requests blocked. Each visitor gets one live build per UTC day. A shared $3 fund caps total reserved and spent model calls unless Gabe explicitly configures a different fund.

A page that runs out of tokens is not published. A 402 pauses new calls; it does not trigger a retry loop. You can inspect the model and reported cost on every saved build.
