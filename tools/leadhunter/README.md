# leadhunter

`node tools/leadhunter/bin/leadhunter.mjs run [--publish]` (or `npm link --ignore-scripts` once, then `leadhunter run`) from the Corvus repository (Node 22.13+).
Set the variables in `.env.example` in your environment. API Anything performs all source reads; blocked/unconfigured sources are reported, never fabricated. No outreach is sent. Full setup and schema contract: [docs/leadhunter.md](../../docs/leadhunter.md).
