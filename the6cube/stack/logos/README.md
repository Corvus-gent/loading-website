# Official logos
Drop each project's official logo here as SVG, named:
javascript.svg rust.svg c.svg cplusplus.svg webassembly.svg haskell.svg prolog.svg lean.svg k.svg bqn.svg typst.svg threejs.svg
Take them from each project's own brand/press page and follow its usage rules. A tile without a file shows its monogram.

## Sources and credits

The SVG files are distributed unchanged and identify technologies used on this page.

| Tile | Original artwork and terms |
| --- | --- |
| JavaScript | [Chris Williams’ JS community mark and original SVG](https://github.com/voodootikigod/logo.js/blob/master/js.svg), MIT. [OpenJS Foundation announcement](https://openjsf.org/blog/jsconf-brand-and-js-logo-and-wordmark-contributed). |
| Rust | [Rust project artwork](https://github.com/rust-lang/rust-artwork/blob/master/logo/rust-logo.svg), © the Rust Foundation, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). [Trademark policy](https://rust-lang.org/policies/media-guide). |
| C | [C language website SVG](https://www.c-language.org/logo.svg). The committee-approved site describes the mark and credits the source in its [FAQ](https://www.c-language.org/faq). |
| WebAssembly | [Carlos Baraza’s original icon](https://github.com/carlosbaraza/web-assembly-logo/blob/master/dist/icon/web-assembly-icon.svg), [CC0](https://github.com/carlosbaraza/web-assembly-logo/blob/master/LICENSE). [WebAssembly project selection](https://github.com/WebAssembly/design/issues/980#issuecomment-281421014). |
| Haskell | [Haskell.org wordmark](https://www.haskell.org/img/haskell-logo.svg). The language emblem was designed by Darrin Thompson and Jeff Wheeler. [Haskell.org source and license](https://github.com/haskell-infra/www.haskell.org). |
| Prolog | The browser uses Tau Prolog. [Tau Prolog download page](https://tau-prolog.org/downloads) and [original icon](https://github.com/tau-prolog/tau-prolog/blob/master/logo/tau.svg), BSD-3-Clause. |
| Lean | [Lean FRO’s official transparent SVG with ™](https://lean-lang.org/logos/). [Trademark policy](https://lean-lang.org/trademark-policy/). |
| BQN | [Marshall Lochbaum’s original BQN emblem](https://github.com/mlochbaum/BQN/blob/master/logo.svg), ISC. |
| Typst | [Typst’s own wordmark](https://typst.app/assets/images/typst.svg), used to identify the compiler in the technical stack. [Brand guidelines](https://typst.app/legal/brand/). |
| Three.js | [three.js project icon](https://github.com/mrdoob/three.js/blob/dev/files/icon.svg), MIT. |

The k tile uses the language name. The [ngn/k implementation](https://codeberg.org/ngn/k) used in CI does not supply an SVG logo. The C++ tile retains its label pending permission under the [Standard C++ Foundation’s terms](https://isocpp.org/home/terms-of-use). On the next site build, either tile can pick up its approved SVG under the filename above.
