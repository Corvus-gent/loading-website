# Web design upgrade

## When to use

Use this for an existing page or site whose interface works but lacks hierarchy or a clear identity. Read its content, visual assets, type, and current interaction patterns first. Identify the page's primary job and the actions readers already rely on.

## Three moves

1. **Choose one material.** Pick a reference with concrete visual consequences, such as a printed programme, a field notebook, or a night-circus poster. Let it govern type, spacing, surface, rules, and image treatment. For ink on plum, use a matte plum ground, warm ink, quiet print rules, and existing artwork.
2. **Build one hero moment per screen.** Choose oversized editorial type or one hero object. Give it space and let supporting content step down in size and contrast. Replace equal-weight card grids with reading order, lists, or sections whenever the content has a clear sequence.
3. **Reserve one signal colour.** Use it for the thing that matters on that screen. Give secondary actions a quieter visual treatment with clear affordances. Warm gold can identify the Corvus lantern and the primary action. Keep focus, errors, and status independently perceivable.

## Checklist

- [ ] Name the material, primary task, and hero for each screen.
- [ ] Limit type to a display face, a text face, and a small set of sizes.
- [ ] Remove decorative borders, panels, badges, and competing hero treatments.
- [ ] Keep every meaningful link, action, route, and piece of content discoverable.
- [ ] Check small screens, light and dark palettes, contrast, focus, keyboard order, reduced motion, and touch targets.
- [ ] Run the existing build and tests. Review rendered screens at desktop and mobile widths.

## Before and after prompts

**Before** — “Make this site feel premium. Add gradients, feature cards, and colourful CTAs.”

**After** — “Treat this as a printed night-circus programme. Let one large Bodoni Moda heading lead each screen, use Instrument Sans for reading, and arrange supporting links as an editorial list. Reserve gold for the primary action and lantern. Preserve routes, content, controls, and keyboard behaviour.”

**Before** — “Redesign this dashboard with a grid of modern tiles.”

**After** — “Treat this as a single-page report. Lead with the one figure readers came for, group supporting metrics below it with type and spacing, and use a single action colour. Keep the original data, chart labels, and navigation.”

## Anti-patterns

- Card soup that makes unrelated items look equally important.
- Gradients everywhere or materials that change between sections.
- Five accent colours competing with the primary action.
- A large picture and a large headline fighting for the same first glance.
- Removing labels, focus rings, or routes to achieve a cleaner screenshot.
