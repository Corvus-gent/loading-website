# Bodoni Moda

Homepage display font: Bodoni Moda, weight 700, optical size 96. Latin and Latin Extended WOFF2 subsets are self-hosted; there are no Google Fonts requests at runtime.

Source: https://fonts.google.com/specimen/Bodoni+Moda
Upstream: https://github.com/indestructible-type/Bodoni
Distribution and license: https://github.com/google/fonts/tree/main/ofl/bodonimoda

This is the selected open font for Corvus's fashion-inspired display direction, not Prada's bespoke logo lettering.
