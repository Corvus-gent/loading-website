# PROMPT

The broken baseline is the waiting cursor. A single bent stroke draws the back, brow and beak of a bird facing the next command.

Gabe’s open-source tools and live hacking give the symbol a home. The outline can also read as a key, especially at a distance. Use the heavier small proof in a browser and embroider the main contour at chest size.

Type pairing: DejaVuSansMono with DejaVu Sans Mono. The kit includes independent vector lettering. Palette roles are defined in palette.json.
