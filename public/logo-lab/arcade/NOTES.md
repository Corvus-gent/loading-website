# ARCADE

A left-facing idle sprite waits for a second player. Its blinking eye and two loose pixels make the static grid feel like a frozen frame.

The Twitch overlay and the language cycle suit Gabe’s live sessions. The sprite can look like a chick when isolated. Favor square applications, and use a coarse, single-color screen print for merch.

Type pairing: DejaVuSansMono-Bold with DejaVu Sans Mono. The kit includes independent vector lettering. Palette roles are defined in palette.json.
